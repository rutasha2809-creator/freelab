# Фрилаб — трекер клиентов

Веб-приложение для учёта клиентов-фрилансера: постоянные (ежемесячные) клиенты
и разовые задачи, суммы, плановые и фактические даты оплат.

## Возможности

- Добавление клиентов с типом «Постоянный» или «Разовый»
- Записи о платежах: суть задачи, сумма, плановая дата, фактическая дата оплаты
- Дашборд: сколько ожидается в этом месяце, сколько получено, сколько ожидается оплаты, сколько просрочено
- Отдельные вкладки для постоянных клиентов и разовых задач
- Отметка «оплачено» в один клик
- Экспорт / импорт данных в JSON (резервная копия), очистка всех данных

## Как запустить

Это статическое веб-приложение без сборки и без сервера — просто откройте
`index.html` в браузере.

Для разработки удобнее поднять локальный сервер (чтобы избежать ограничений
браузера на локальные файлы), например:

```bash
npx serve .
# или
python3 -m http.server 8080
```

## Хранение данных

Все данные хранятся в `localStorage` браузера, на вашем устройстве. Никуда
не отправляются. Используйте кнопку «Скачать резервную копию» в разделе
Настройки, чтобы не потерять данные при смене браузера или устройства.
